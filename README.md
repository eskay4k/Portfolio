# visualsbyeskay

Static portfolio for eskay

## Vercel deployment

Import eskay4k/Portfolio into Vercel, use Other framework and public output directory, no build command or environment variables are required

Pushes to main publish production changes, other branches create previews

Edit public/index.html, public/style.css, public/app.js and public/content.json, media is in public/assets

The contact form opens an email draft addressed to eskayinquiries@gmail.com
